# AeonCAT — CAT-Level Long-Form Reader

A distraction-free, minimalist dark-mode web application engineered to generate and read authentic 1,000–3,000 word CAT VARC analytical treatises on any topic.

## Features
- **Minimalist Dark Reader**: Pure unbolded typography (Lora Serif, Inter Sans, Mono) with 1.8 line height.
- **Deep Research Engine**: Generates 1,000 to 3,000-word essays with periodic sentences, hypotaxis, high-register vocabulary, and dialectic critique.
- **Interactive Lexicon**: Click any word for instant definitions, phonetics, etymologies, and save to your CAT Vocab Bank.
- **Vercel & Multi-Device Ready**: Seamless iPad and desktop reading.

## Vercel Deployment
1. Import this repository into Vercel.
2. In Project Settings -> Environment Variables, add:
   - `VITE_GEMINI_API_KEY` = `your_gemini_api_key`
3. Deploy!
